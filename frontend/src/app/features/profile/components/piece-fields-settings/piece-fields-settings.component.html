Champs par défaut des pièces

Colonnes (et leur ordre) pour chaque type de pièce — trois vues : import des données (source), affichage dans l'app et rapport PDF.

Colonnes par type de pièce

Pour chaque type de pièce, la vue « Import des données » (source) définit les champs réellement importés et leur ordre. Les vues « Affichage dans l'app » et « Rapport PDF » en dépendent : un champ non importé ne peut y être affiché (il apparaît verrouillé). Les champs marqués sont obligatoires (toujours importés). Décocher une colonne la masque de la vue ; tout décocher masque le tableau entier. Utilisez « Réinitialiser » pour revenir à toutes les colonnes.

Réinitialiser avec la configuration source ?

Votre configuration de colonnes va être remplacée par la configuration source (celle du compte administrateur). Vos réglages de colonnes personnalisés seront écrasés. Cette action n'affecte pas les tableaux déjà enregistrés.
